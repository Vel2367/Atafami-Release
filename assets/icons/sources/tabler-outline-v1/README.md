# Tabler Outline icons for ScriptUI_defolt

Six supplied white 128 × 128 transparent PNGs are published in `assets/icons/`:
run, eye, search, settings, arrows-move and arrows-diagonal-2. Their bytes have
not been changed. SHA-256s, upstream commit and exact source URLs are in
`SOURCES.json`; `file` paths are relative to this directory. Original archive
PNG paths are retained as `archive_file`.

The supplied original SVGs are preserved in `svg/`; their Git blob hashes were
verified against the manifest. Runtime loads only the PNGs from Atafami-Release.
Tabler icons are by Paweł Kuna, under the included MIT `LICENSE.txt`.
