## Menu backgrounds

[menu/halloween.jpg](menu/halloween.jpg) — исходный JPEG 853 × 480, предоставленный пользователем. Байты не изменены; SHA-256: `f92105d5999221a4976c5f17f6de3e6fd958ad21939eb741c6a85f438dbe3769`. Сведения о файле: [menu/SOURCES.json](menu/SOURCES.json).

В Real изображение размещается в `atafami/ui_cache/Menu/halloween.jpg`. Порядок установки показан в [инструкции UI](../ui/README.md). Пользователь может добавить собственные PNG/JPG в тот же каталог и выбрать их в Settings → Background → Image.

## Icons

В `assets/icons/` опубликовано **33 PNG**. Имена являются частью публичных URL и сохранены для совместимости. Каждая библиотека Source владеет своим resolver и кэшем; зависимости от ThemeUI у нового UI нет.

Текущий ScriptUI_defolt использует Tabler-иконки вкладок, `fa--arrows.png`, `iconmind--chevrons-up-down-outline-bold.png`, `dashicons--arrow-up-alt2.png`, `icon-park-solid--click.png`, `gravity-ui--gear.png` и `akar-icons--discord-fill.png`.
